# Dotfiles

Personal configuration files for shell, terminal, and Neovim.

## What is here

- `zsh/`: shell config and aliases
- `alacritty/` and `kitty/`: terminal emulator configs
- `nvim/`: Neovim config (Lua plugins and settings)
- `bin/`: helper scripts
